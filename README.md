# Edirne (Одрин) Drone 3D Model – Color Textured GLB

Color textured 3D model (`.glb`) and photorealistic aerial view of **Edirne (Одрин), Turkey** city center.

## Files

| File | Description |
|------|-------------|
| `Edirne_Odrin_drone_120m_center_textured.glb` | Color textured plane mesh (GLB) with high-res aerial texture |
| `edirne_odrin_drone_120m_center.jpg` | Source aerial photo (DJI Mavic Mini 2 style, 120 m altitude, looking at center / Selimiye Mosque) |

## Capture simulation
- **Drone**: DJI Mavic Mini 2
- **Altitude**: 120 m
- **View**: Towards the historic center (Selimiye Camii by Mimar Sinan)
- **Style**: Photorealistic color texture, red-roofed Ottoman houses, Tunca & Meriç rivers, Thracian plain

## How to use
1. Download the `.glb`
2. Open in Blender, Unity, Unreal, Three.js, Babylon.js, Sketchfab, etc.
3. The mesh is a UV-mapped plane with the full color texture applied (PBRMaterial / baseColorTexture)

Generated with Grok Imagine (xAI) + trimesh.
